# [Lapinite](https://github.com/Lapinite)

Founder and developer of **Leviathan**.

I build software around Minecraft with a focus on launchers, client systems, authentication, backend services, APIs, security, infrastructure and connected platform features.

## Leviathan

Leviathan is a Minecraft platform I am building around a custom launcher and client experience.

Current areas of development include:

- Desktop launcher
- Minecraft client systems
- Microsoft and Minecraft authentication
- Account identity and verification
- Backend services
- APIs
- Security systems
- Server integrations
- Profiles and social features
- Cosmetics and customization
- Creator tools
- Marketplace systems
- Economy systems
- Update infrastructure
- Documentation
- UI and product design

## Leviathan Launcher

A custom Minecraft Java desktop launcher built around account management, customization, security and a better overall player experience.
